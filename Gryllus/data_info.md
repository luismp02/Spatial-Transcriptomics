# Gryllus datashare Overview

## Base Paths

| Path | Description |
|------|------------|
| `~/projects/datashare/grillus/` | Main directory for the Grillus project data. |
| `~/projects/datashare/grillus/genome/` | Contains genomic reference data (Harvard + IAB). |
| `~/projects/datashare/grillus/240902/` | Raw sequencing data from sample 240902 + FASTQs. |
| `~/projects/datashare/grillus/files/` | Various CSV and PDF files with gene information and analysis. |
| `~/projects/datashare/grillus/outs/filtered_feature_bc_matrix/` | Processed Visium matrix data. |
| `~/projects/datashare/grillus/outs/spatial/` | Spatial data files for Visium. |

## Files per Directory

### Genome Reference (Harvard)
| File | Description |
|------|------------|
| `Gbi_Genes.gff` | Gene annotation file in GFF format. |
| `Gbi_genome.fa` | Genome sequence in FASTA format. |
| `Gbi_maker.transcripts.fa` | Transcript sequences generated by Maker. |

### Sample 240902
| File | Description |
|------|------------|
| `GMRS146.R1.fastq.gz` | Forward read of sequencing data in FASTQ format. |
| `GMRS146.R2.fastq.gz` | Reverse read of sequencing data in FASTQ format. |
| `md5_240902.txt` | MD5 checksum file for integrity verification. |

### Gene Information Files
| File | Description |
|------|------------|
| `de_gene_names_growth.csv` | Differentially expressed genes related to growth. |
| `dr_regeneration.csv` | Downregulated genes in regeneration. |
| `ur_regeneration.csv` | Upregulated genes in regeneration. |
| `gene_name_scaring.csv` | Genes associated with scarring processes. |
| `liste_gene_and_code.csv` | List of genes with their corresponding codes. |

### Visium Processed Matrix Data
| File | Description |
|------|------------|
| `matrix.mtx.gz` | Sparse matrix containing gene expression counts. |
| `barcodes.tsv.gz` | Barcode sequences identifying spatial spots. |
| `features.tsv.gz` | Feature metadata including gene names. |

### Visium Spatial Data
| File | Description |
|------|------------|
| `tissue_hires_image.png` | High-resolution tissue image. |
| `tissue_positions.csv` | CSV file with spatial positions of tissue spots. |
| `scalefactors_json.json` | JSON file with scaling factors for image alignment. |
